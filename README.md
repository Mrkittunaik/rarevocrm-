# RAREVO CRM

A multi-business lead CRM for RAREVO clients. It has Excel-style sheets, a master sheet and follow-up reminders. It also has two read-only connections:

- **Rarevo WhatsApp:** your WhatsApp automation platform.
- **Meta:** ad spend, and leads from Facebook and Instagram lead forms.

There are no npm packages to install. You only need Node 18 or newer, or Docker.

## Run it

**With Node (Windows, Mac or Linux)**

```bash
cd rarevo-crm
copy .env.example .env        # macOS/Linux: cp .env.example .env
# edit .env and set ADMIN_EMAIL / ADMIN_PASSWORD
npm start                     # or: node server/server.js
```

Then open http://localhost:4000 and sign in with the admin email and password from `.env`. The defaults are `admin@rarevo.local` / `admin123`. Change the password after signing in, from the avatar menu → Change password.

**With Docker (same setup as your Rarevo WhatsApp platform)**

```bash
cp .env.example .env
docker compose up -d --build
```

Data is kept in `./data/db.json`. Back up that file, or use the JSON backup in the app.

## Deploy free on Cloudflare (from GitHub)

The `cloudflare/` folder runs the same CRM on **Cloudflare Workers** (free plan). Data is kept in a Cloudflare **Durable Object** (SQLite storage), which the free plan includes, and website forms and the WordPress plugin work over HTTPS.

1. **Push this folder to a GitHub repository.** Don't upload `data/` or `.env`; `.gitignore` already skips them.
2. In the **Cloudflare dashboard**, go to **Workers & Pages → Create application → GitHub**, choose the repository and click **Save and Deploy**. The Worker name must be `rarevo-crm`, the same as `name` in `wrangler.toml`.
3. **Set your admin password before you open the site:** your Worker → **Settings → Variables and Secrets → Add → Secret**, name `ADMIN_PASSWORD`.
4. **Open** `https://rarevo-crm.<your-subdomain>.workers.dev/#/admin` and sign in with login ID `admin`.
5. **Optional custom domain:** your Worker → **Settings → Domains & Routes → Add → Custom domain**, for example `crm.rarevo.in` (the domain must be on Cloudflare).

Every push to GitHub redeploys automatically, and your data stays in the Durable Object.

**Free plan notes**
- The free plan covers about 100,000 requests a day, which is plenty for a CRM.
- The whole database is saved on every change, which suits up to roughly tens of thousands of records.
- WhatsApp auto-sync runs every 30 minutes (Cron Trigger), but Cloudflare can only reach a Rarevo WhatsApp platform that has a public address, not one on `localhost`.

## Logins and roles

| Role | Who | Sees |
|---|---|---|
| **System admin** | You (RAREVO) | Every business, all master sheets, all follow-ups, all users. Can create businesses and client logins. |
| **Business admin** | Your client (business owner) | Only **their** business: Overview, Sheets, Master sheet, Follow-ups, WhatsApp, Meta ads, Email marketing, Reports, Team, Settings. They never see the businesses list or other clients. They can add their own staff. |
| **Staff** | The client's sales people | Only the records assigned to them inside that business. |

**Login pages and login IDs**
- **System admin:** signs in at `http://localhost:4000/#/admin` with login ID `admin` (set `ADMIN_USERNAME` / `ADMIN_PASSWORD` in `.env`). From the Businesses page you can open any business directly.
- **Each business:** gets its own branded login page, `http://localhost:4000/#/login/<business-name>`. Share this link with the client and their team.
- **Login IDs:** generated from names, for example `varrun.admin` for the business admin and `varrun.rajitha` for an employee. Passwords are generated by the system.
- **Sharing:** after creating a login you get a ready message to send with **Send on WhatsApp**, **Send with Gmail** or **Copy message**. Use **New password** if someone forgets theirs.

**Sheet access (per sheet: View / Edit)**
- Business admins always have full access.
- For each sheet, the admin chooses which employees can view it and which can edit it (sheet tab ▾ → Access, or Team & access → Access).
- The master sheet has its own "who can open it" setting.
- Someone without access sees **"You don't have access – Request view / edit access"**. The admin sees the request in the bell menu and under Team & access, and can **Allow** or **Deny** it.
- Employees always see the records assigned to them.
- All of this is checked on the server, not just hidden on screen.

**Working in a sheet (like Google Sheets / Excel)**
- **Selecting and editing:** click a cell to select it (blue border, cell name and value shown in the bar on top). To edit, double-click, press Enter, or just start typing. Enter saves and moves down, Tab moves right, Esc cancels, and the arrow keys move between cells.
- **Copy and paste:** Ctrl+C copies the selected cell and Ctrl+V pastes into it. Delete clears it.
- **Dropdowns:** Status, Priority, Source and POC are dropdown chips.
- **Columns:** drag a column border to resize it. Double-click a header to rename it. The ▾ menu on a header lets you sort, rename, insert, hide or delete columns, and **+** adds a new column.
- **Sheet tabs** are at the bottom, with a ▾ menu on each tab. **Categories** are on top. **Full screen** hides everything except the sheet (Esc to exit). **Wrap** turns multi-line text on or off.

## Website plugin and forms (business → 🌐 Website & forms)

- **Any website (HTML, Shopify, Wix, Webflow, custom):** paste the one-line script shown in the CRM before `</body>`. Every form filled on the site is copied into the chosen sheet. Passwords and card fields are never sent, and UTM source and campaign are kept. Someone who fills a form again is updated, not duplicated.
- **WordPress / WooCommerce:** download the plugin from the same page (`public/downloads/rarevo-crm-connector.zip`, source in `wordpress/`) and enter the CRM address and website key under Settings → RAREVO CRM.
  - It captures Contact Form 7, WPForms, Elementor, Gravity Forms and Fluent Forms, as well as new user sign-ups and WooCommerce customers and orders.
  - **Sync existing users now** imports everyone already registered on the site.
- **Forms:** use **Create form**, add questions (short text, long text, phone, email, number, date, dropdown, checkbox), choose the sheet, and share the link (`#/f/<form>`) or the embed code. Questions called Name, Phone, Email and Message fill those fields, and other questions become sheet columns.
- **Hosting:** a live website can only reach the CRM when the CRM is on a public address, such as `https://crm.yourdomain.com` (a VPS, or a Cloudflare Tunnel from your PC). On localhost you can test with the **Send a test lead** button.

## System admin shortcuts
- **Client view / Open as:** enter any business as its admin or employee without a password. A blue bar shows who you are viewing as, with **Back to RAREVO admin**.
- **Profile menu → Business login pages:** every business's login link, its admin login ID, and **Open as admin**.

## Sheet formatting
- Select a cell, then use **B** (bold, Ctrl+B), **I** (italic, Ctrl+I), **A** (text colour), the bucket (row fill colour, for the selected row or all ticked rows), or **✕** (clear formatting).
- To rename a header, double-click it and type. Right-click a header (or use ▾) for sort, rename, insert and delete.

## What's inside

| Area | What it does |
|---|---|
| **Businesses (home)** | A card for each client with WhatsApp/Meta health, records, sheets, WhatsApp contacts and 30-day spend. You can add, search and filter businesses (Active, Onboarding, Paused). |
| **Sheets** | Excel-like grid with editable cells, sorting, search and filters (status, priority, source, POC). It also has colour-coding, custom columns (text, number, date, dropdown, checkbox), bulk select, assign, move and delete, and CSV export. |
| **Upload sheet** | Upload CSV or Excel (.xlsx/.xls). Each tab of an Excel file becomes its own sheet (Sheet 1, Sheet 2 …). You match each column to a CRM field or keep it as a column, and duplicate phone numbers are skipped. |
| **Categories** | Each sheet has a category (Bags, Real estate …). Category chips filter the sheet tabs and the master sheet. |
| **Sheets workspace** | A side panel with Categories, then Master sheet, then the sheet list, plus a **Full screen** button (Esc to exit). **Columns & headers** lets you rename any header, including built-in ones such as Phone → “WhatsApp number”, hide columns you don't use, and add or edit your own columns. You can also double-click a header to rename it. |
| **Email marketing** | Records each campaign's sent, delivered, opened, clicked, replies, leads, unsubscribed and cost. Add them by hand or import a CSV from Gmail, Mailchimp, Brevo, Zoho or similar. The page shows open rate, click rate, cost per lead, and email cost in Reports. |
| **Master sheet** | Every record from every sheet of a business in one grid, with Sheet and Category columns and all custom columns merged by name. There's also a global master sheet across all businesses. Edits there update the original sheet. |
| **Auto fields** | Date added is recorded automatically. The closure date fills in when status becomes Won or Lost. Sale price, priority, next follow-up and POC are on every record. |
| **Access** | Admins see everything. A POC only sees records assigned to them, and the server enforces this. New leads can be shared out to POCs in turn (round-robin), per business. |
| **Follow-ups** | Grouped by Overdue, Next 30 min, Today, Tomorrow and This week. A pop-up and browser notification appear 30 minutes before each follow-up while the CRM is open. You can mark a follow-up done or snooze it. |
| **Google Calendar** | The Meet button opens a filled-in Google Calendar event. Guests are the business's default emails, the POC and the lead. |
| **WhatsApp (view-only)** | Shows contacts, a summary and chat history pulled from Rarevo. You can add selected contacts, or all new ones, to any sheet. Replies and automations stay in Rarevo. |
| **Meta ads** | Daily spend, impressions, clicks and leads per campaign, synced from the Marketing API and stored in the CRM. Also shows cost per lead, won revenue from Meta leads and ROAS. You can import lead-form leads into a sheet, add spend by hand or import a spend CSV. |
| **Reports** | This week, last week, month or custom dates. Broken down by POC, by sheet and by source, with revenue, win rate, Meta spend and ROAS. Downloads as CSV, which opens in Excel. |
| **Team** | Add admins and POCs with their own logins. |

## Connect Rarevo WhatsApp

1. In Rarevo, open **Businesses → (business) → CRM → Connect to CRM** and copy the **API URL**, **API key** and **API password**.
2. In the CRM, open the business card → **Connect** → **Rarevo WhatsApp**, paste the three values and press **Connect**.
3. On the **WhatsApp** tab, press **Sync now**. Contacts also re-sync automatically every `SYNC_MINUTES`.

The CRM calls (GET only): `/summary`, `/contacts?page=&limit=` and `/contacts/:number/messages`, with the headers `Authorization: Bearer <API key>` and `X-Api-Password: <API password>`.

> **Docker tip:** if the CRM runs in Docker and Rarevo runs on the same PC, use `http://host.docker.internal/api/crm/v1` instead of `http://localhost/api/crm/v1`.

If your Rarevo API uses different field names, edit `normContact` / `normMessage` in `server/integrations.js`. They already accept the common names (`number`/`phone`/`wa_id`, `name`/`profile_name`, `last_message`, `direction`/`from_me` …).

## Connect Meta

1. In Meta Business Settings, go to **System users** → **Generate token**, with the permissions `ads_read`, `leads_retrieval`, `pages_show_list`, `pages_read_engagement` and `pages_manage_ads`.
2. In the CRM, open the business → **Connect** → **Meta ads** and enter:
   - the **Ad account ID** (`act_…`)
   - the **access token**
   - the **Facebook Page ID**, which is needed for lead forms
3. On the **Meta ads** tab:
   - **Sync spend** stores day-by-campaign spend.
   - **Import lead-form leads** adds leads to a sheet. Extra form questions become columns.

The token is kept on the server only and is never sent back to the browser.


## Notes

- **Demo mode:** if you open `public/index.html` without the server, it runs in demo mode, with sample data kept in that browser only.
- **Excel import:** reading `.xlsx` loads the SheetJS library from cdnjs, so it needs internet. CSV import works offline.
- **Reminders:** reminders appear while the CRM is open in a browser. WhatsApp or email reminders would need a sending service (for example your Rarevo platform) added to `server/server.js`.

## Excel-style sheet (v5)

- Click a column letter to select the column, or a row number to select the row. Shift-click to select more. Drag across cells to select a block.
- Delete clears the selection. Ctrl+C / Ctrl+V copies and pastes blocks, including from Excel. Ctrl+Z / Ctrl+Y undo and redo. Ctrl+B / Ctrl+I format the selection.
- Drag a column letter to move the column (or use Alt+←/→). Drag a row number to move the row. Drag the bottom edge of a row number to change its height; double-click the edge to reset it.
- Use the blue square at the corner of the selection to fill down.
- Right-click a column letter for: Clear, Delete (goes to *Deleted columns*), Insert left/right, Rename, Move, Swap with…, and Sort.
- Sheet tab ▾ menu: Upload into this sheet, Undo last upload, Remove junk rows, and Deleted columns.

## Upload Excel

- The heading row is found automatically, and title or "Total…" rows are skipped.
- For an existing sheet, choose one of these modes:
  - **Replace:** the sheet becomes exactly like the file.
  - **Update + add**
  - **Only add new**
- You see a summary before anything changes. Status, POC, follow-ups and colours are kept for matching people.

## Master sheet

The **Master sheet** is in the left rail. It shows every sheet plus WhatsApp chats (auto-added), website, forms and Meta leads. It shows one row per person and has source filters.
