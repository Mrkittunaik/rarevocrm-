=== RAREVO CRM Connector ===
Sends website leads, new sign-ups and WooCommerce customers to RAREVO CRM.

1. Upload the zip in WordPress: Plugins -> Add New -> Upload Plugin, then Activate.
2. Settings -> RAREVO CRM: paste the CRM address and the website key (from the CRM: business -> Website & forms).
3. Press "Send a test lead", then "Sync existing users now" to import everyone already registered.
